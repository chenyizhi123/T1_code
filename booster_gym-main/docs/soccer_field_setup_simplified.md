# 足球场设置简化方案

## 实施内容

### 1. 简化足球场位置设置
在 `t1.py` 中：
```python
field_pose = gymapi.Transform()
field_pose.p = gymapi.Vec3(*pos)
field_pose.p.z = -0.01  # 只调整高度，让场地表面贴近地面
```
- 移除了复杂的X/Y偏移计算
- 保持URDF原有的几何定义
- 足球场按照URDF定义出现在：X:[0,12], Y:[0,9]

### 2. 调整机器人初始位置
在 `T1.yaml` 中：
```yaml
init_state:
  pos: [2.0, 2.0, 0.72] # x,y,z [m] - 机器人在足球场左下角附近
```

## 场景布局

### 足球场
- **位置范围**：X轴 [0, 12] 米，Y轴 [0, 9] 米
- **中心位置**：(6, 4.5, 0)
- **球门位置**：Y=9 处，两个门柱在 X=4.825 和 X=7.175

### 机器人
- **初始位置**：(2, 2, 0.72) - 在场地左下角附近
- **距离球门**：约7米，适合训练踢球

### 足球
- **默认位置**：机器人前方1米，即 (3, 2, 0.11)
- **位置灵活性**：可通过配置文件调整

## 优势

1. **代码简洁**：移除了不必要的坐标转换
2. **逻辑清晰**：足球场按URDF定义放置，机器人位置通过配置调整
3. **训练合理**：机器人在场地内，有明确的球门目标
4. **易于维护**：减少了出错可能性
