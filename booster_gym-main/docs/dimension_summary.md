# 维度变化总结

## 基础行走模型（原始）
- **观察空间（obs）**：47维
- **特权观察空间（privileged_obs）**：14维
- **动作空间（actions）**：12维

## 足球环境模型（新）
- **观察空间（obs）**：60维 = 47 + 13
- **特权观察空间（privileged_obs）**：20维 = 14 + 6
- **动作空间（actions）**：12维（不变）

## 详细分解

### 观察空间（60维）
1. **基础观察（47维）**
   - 重力投影：3维
   - 基座角速度：3维
   - 命令：3维
   - 步态相位：2维（cos, sin）
   - 关节位置：12维
   - 关节速度：12维
   - 上一步动作：12维

2. **足球观察（13维）**
   - 球相对位置：3维
   - 预留扩展：10维

### 特权观察空间（20维）
1. **基础特权观察（14维）**
   - 基座质量缩放：4维
   - 基座线速度：3维
   - 高度测量：1维
   - 推力：3维
   - 扭矩：3维

2. **足球特权观察（6维）**
   - 球世界坐标位置：3维
   - 球世界坐标速度：3维

## 网络架构影响
- **Actor网络**：输入层需要从47扩展到60
- **Critic网络**：输入层需要从14扩展到20

## 使用建议
1. 使用`ModelAdapter`工具进行权重迁移
2. 新增维度使用小随机值初始化（std=0.01）
3. 使用较小学习率（1e-6）进行微调
4. 监控前1000步确保行走稳定性
