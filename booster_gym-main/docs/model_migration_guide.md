# 模型维度迁移指南：从47维到60维

## 背景

当我们想要在已训练好的行走模型基础上添加新功能（如足球感知）时，需要扩展输入维度。本指南说明如何从47维输入模型迁移到60维输入模型。

## 变化说明

### 观察空间扩展
- **原始**：47维（基础行走观察）
- **新增**：13维（足球相关观察）
  - 球相对位置：3维
  - 预留扩展：10维
- **总计**：60维

### 特权观察空间扩展
- **原始**：14维（基础特权信息）
  - 基座质量缩放：4维
  - 基座线速度：3维
  - 高度测量：1维
  - 推力：3维
  - 扭矩：3维
- **新增**：6维（足球特权信息）
  - 球世界坐标位置：3维
  - 球世界坐标速度：3维
- **总计**：20维

### 修改的文件
1. `envs/t1.py` - 更新`_compute_observations()`方法
2. `envs/T1_phase1.yaml` - 更新`num_observations: 60`
3. `utils/model_adapter.py` - 新增模型适配工具
4. `train_with_adapter.py` - 新增迁移训练脚本

## 使用步骤

### 1. 准备旧模型
确保你有一个训练好的47维模型检查点，例如：
```
checkpoints/T1_walking_47d.pth
```

### 2. 适配模型
运行适配脚本：
```bash
python train_with_adapter.py --old_checkpoint checkpoints/T1_walking_47d.pth --config envs/T1_phase1.yaml
```

这会：
- 加载旧的47维模型
- 扩展输入层以接受60维输入
- 保存适配后的模型为`T1_walking_47d_adapted_60d.pth`

### 3. 继续训练
使用生成的命令开始训练：
```bash
python train.py --config envs/T1_phase1.yaml --checkpoint checkpoints/T1_walking_47d_adapted_60d.pth
```

## 技术细节

### 权重适配策略
- **前47维**：保持原有权重不变
- **新13维**：使用小随机值初始化（0.01标准差）
- 这确保模型初始行为不会显著改变

### 训练建议
1. **学习率**：使用较小的学习率（1e-6），避免破坏已学习的行走技能
2. **监控**：密切观察前1000步的表现
3. **渐进式**：先让机器人适应有球的环境，再添加与球交互的奖励

## 阶段性训练计划

### Phase 1（当前）
- 环境中有球和球场
- 机器人可以感知球的位置
- 但所有足球相关奖励权重为0
- 目标：保持行走稳定性，适应新环境

### Phase 2（未来）
- 启用`approach_ball`和`face_ball`奖励
- 机器人学习接近和面向球

### Phase 3（未来）
- 启用`align_goal`和`kick_velocity`奖励
- 机器人学习踢球

### Phase 4（未来）
- 启用`goal_scored`奖励
- 完整的足球技能

## 常见问题

### Q: 为什么不直接训练60维模型？
A: 从零开始训练需要大量时间。利用已有的行走技能可以大大加快训练速度。

### Q: 新增的13维会影响行走吗？
A: 初始时影响很小，因为新维度的权重很小。随着训练，模型会逐渐学习利用这些信息。

### Q: 可以冻结部分网络吗？
A: 可以。如果发现行走性能下降，可以冻结网络的后几层，只训练输入层。
